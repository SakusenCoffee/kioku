# Kioku-only Features

Things Anki on a computer doesn't do, all off until you turn them on:

| Feature | Variants | Where |
| --- | --- | --- |
| [Sync server on the phone](sync-server.md): AnkiDroid, Kioku's profiles and Anki on your computers sync with the phone instead of AnkiWeb | iPhone, Android native | Preferences › Advanced |
| [AnkiDroid's media](ankidroid.md): a profile uses AnkiDroid's media folder, so big media is stored once; syncs when you switch apps | Android native | Preferences › Advanced |
| [Remote desktop](remote-desktop.md): use the phone's Anki from a computer's web browser or VNC viewer | Android Termux | Settings › Remote desktop |
