# Android, native

> **Applies to:** Android native

Needs Android 9 or newer on a 64-bit ARM phone (arm64-v8a: nearly every
phone from the last years).

1. On the phone, download `Kioku-Android-<version>-arm64.apk` from the
   [latest release](https://github.com/krmanik/kioku/releases/latest).
2. Open it. Android asks to allow installing apps from your browser or file
   manager: allow it, go back, and tap **Install**.
3. Open **Kioku**.

To update, download the new APK and install it the same way. Data stays.

Kioku runs next to AnkiDroid and the Termux variant; each has its own
collection. To share cards between them, sync (AnkiWeb, or [the phone's own
sync server](../features/sync-server.md)).

Android asks to **allow notifications** the first time the [sync
server](../features/sync-server.md) starts; allow it, or its notification
stays hidden.
