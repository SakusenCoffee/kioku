# Installing & Updating

Every release is on [GitHub Releases](https://github.com/krmanik/kioku/releases/latest):

| File | Variant |
| --- | --- |
| `Kioku-iOS-<version>-unsigned.ipa` | [iPhone and iPad](ios.md) |
| `Kioku-Android-<version>-arm64.apk` | [Android, native](android.md) |
| `Kioku-Termux-<version>-arm64.apk` | [Android, Termux](termux.md) |

Without installing an app:

| Where | |
| --- | --- |
| [kioku.krmanik.workers.dev](https://kioku.krmanik.workers.dev) | [Web browser](web.md) (experimental) |
| `ghcr.io/krmanik/kioku-desktop` | [Self-hosted server](self-hosted.md) (Docker) |

Kioku isn't in the App Store or Google Play. On iPhone and iPad it's also on
[TestFlight](ios.md#testflight) ([sign up](https://forms.gle/fw4YMTdGbgD8nqPe8)).

**Updating keeps your data.** Install the new version over the old one:
collections, media, add-ons and settings stay. Don't uninstall first:
uninstalling deletes the app's data, unless you synced or exported it.

**Before a big update**, sync with AnkiWeb or make a backup (File › Create
Backup), as you would on a computer.
