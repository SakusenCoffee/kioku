# Using Kioku on a Phone

Anki desktop was made for a mouse, a keyboard and big windows. Kioku keeps
Anki unchanged and adapts the way its windows behave:

- [Native apps (iPhone, Android)](native.md): every window full screen,
  popups as cards, Back closes windows.
- [Termux desktop](termux.md): a small desktop with a dock, touch screen or
  mouse pad mode.
- [Your Files](files.md): importing decks, where exports and backups go.
- [Add-ons](addons.md): installing and what works.

The screens inside each window (deck list, reviewer, Browse, editor,
statistics, deck options) are Anki's own; Anki's manual describes them.
